## 배경
FR-C2~C4, FR-C8. 실제 응답 기반 fixture로 공고를 정규화하고 한 트랜잭션에서 적용한다.

## 할 일
- 확정 PRD와 ADR에 따라 구현하고 필요한 실제 응답 fixture/테스트를 추가한다.
- 관련 설계 문서와 실행 절차를 구현과 일치시킨다.
- 구현자 외 claude/codex/agy 두 리뷰를 반영한다.

## 완료 기준
동일 입력 재적재 0 변경, 마감일 변경 1건, decimalDay 변경 0건. 실패/빈/잘린/중복 ID 응답은 공고와 마지막 완전 수집을 변경하지 않는다. KST 마감과 누락 CHECK, 코드 정렬, 원문 보존 및 품질 배지를 검증한다.

CI 통과와 두 리뷰 근거를 PR에 남긴다. 실제 환경에서 미검증인 항목은 완료로 표시하지 않는다.
