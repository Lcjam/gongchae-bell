# 와이어프레임 (텍스트)

> Bootstrap 5 기본 컴포넌트를 쓴다. 차트는 없다. 모바일(360px)에서는 필터가 접힌다.

## 공통 레이아웃
```
┌ 서비스명 ─────────────── [공고 찾기] [알림 받기] ┐
│ (본문)                                          │
└ 마지막 수집: 2026-11-08 14:07 · 출처: 공공데이터포털 · 개인정보처리방침 ┘
```

## 홈 `/`
```
[신입 지원 가능 공고 보기] [정보통신 공고 보기]
── 마감 임박 (D-0~D-3) ──  카드: 기관 · 제목 · D-2 · 마감일      (없으면: "마감 임박 공고가 없습니다")
── 오늘 시작한 공고 ──      목록: 기관 · 제목 · 구분 · 마감일      (없으면 빈 상태)
── 알림 받기 안내 ──        "조건에 맞는 새 공고를 이메일·디스코드로" [알림 받기]
```

## 목록 `/jobs`
```
[필터] 직무(NCS) ▾  지역 ▾  고용형태 ▾  구분(신입 지원 가능/신입만/경력) ▾  상태 ▾  제목 [    ] [검색]
결과 123건 · 조건 요약 · 정렬(마감일순/시작일순)        [이 조건으로 알림 받기]
┌ 기관 │ 제목 │ 직무 │ 지역 │ 고용형태 │ 구분 │ 마감일 │ D-day │ 상태 ┐
│ ...  (확인 필요·품질 경고 배지)                                    │
└─────────────────────────────────────────────────────────────────┘
[< 1 2 3 >]                           (결과 없음: "조건에 맞는 공고가 없습니다")
```

## 상세 `/jobs/{sn}`
```
제목                                   [품질 경고: 깨진 문자 있음 → 원문을 확인하세요]
기관(→ 기관 페이지) · 구분 · 고용형태 · 지역 · 모집 인원 · 기간 · D-day
── 자격 ── / ── 우대 ── / ── 전형 ──
── 전형 단계 · 첨부 ── (상세를 수집하지 않았으면 "상세 정보 미수집")
[원문 보기]  [잡알리오에서 보기](원문이 기관 첫 화면일 때)  [이 기관 공고 이력]
```

## 기관 `/institutions/{code}`
```
기관명 · 기준: 최근 3년(공고 시작일 기준)                         [잡알리오 기관비교 →]
요약: 공고 N건 · 공고상 모집 예정 인원 합계 M명 (숫자로 확인되지 않은 공고 K건 제외)
── 시기 패턴 ── 연도 × 1~12월 공고 수 표
── 직무 분포 ── NCS별 공고 수 표
── 공고 이력 ── 시작일 · 제목 · 구분 · 마감일 · 상태
```

## 알림 신청 `/subscriptions/new`
```
[이메일] [디스코드] 탭
조건: (목록 필터와 같은 항목, 현재 필터가 채워져 있다)    알림 종류: [x] 새 공고 [x] 마감 임박
이메일 [          ]   또는   디스코드 웹훅 URL [          ] (만드는 방법 안내)
고지: 수집 항목 · 목적 · 보유 기간 · 동의를 거부하면 알림을 받을 수 없음(공고 조회는 가능) · 국외 이전(Resend, 미국)
[ ] 위 내용에 동의합니다   [ ] 만 14세 이상입니다          [신청]
→ 완료: "확인 메일을 보냈습니다" (이미 구독 중이어도 같은 문구)
→ 디스코드 완료: "테스트 메시지를 보냈습니다. 관리 링크: … (지금만 표시됩니다)"
```

## 확인 · 관리 · 해지
```
확인:  구독 요약 [구독 확인]                   (만료: "링크가 만료됐습니다. 다시 신청해 주세요")
관리:  채널(이메일은 일부 가림, 디스코드는 종류만) · 상태 · 조건 수정 폼 [저장]  [해지하기 →]
해지:  "해지하면 즉시 삭제됩니다" [해지]  → "해지됐습니다"
다시 받기: 이메일 입력 [보내기] / 웹훅 URL 입력 [확인]
```

## 개인정보처리방침 `/privacy`
목적 · 항목 · 상태별 보유와 파기 · 위탁(Resend)과 국외 이전(미국) · 백업 14일 보관 · VM 소실 시의 한계([ADR-0013](../adr/0013-erasure-journal-host-file.md)) · 권리 행사 방법 · 담당 연락처 · 정책 버전

## 오류
404 · 요청 제한 초과("잠시 후 다시 시도하세요") · 서버 오류(원시 오류와 비밀값은 표시하지 않음)
