공식 공개 JSON 표본은 [fixtures](../fixtures/README.md)에 있다. 운영 게이트웨이 fixture로 사용하려면 래퍼 변환을 명시해야 하며, 이것으로 실제 API 키 호출이나 3년 적재가 검증됐다고 주장하지 않는다.

배포·실발송에는 사용자의 도메인/DNS, 서버 접속, 담당 연락처, API/Resend/운영 알림 설정 및 NAS pull 환경이 필요하다. 비밀값은 환경변수 또는 GitHub Secrets에만 둔다.
