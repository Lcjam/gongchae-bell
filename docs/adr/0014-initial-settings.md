# ADR-0014 초기 설정값

- **상태**: 채택 (2026-11-08). **모두 초기값**이다. 운영하면서 조정하고, 바꿀 때마다 이 문서와 CHANGELOG에 이유를 남긴다. 성능이나 가용성 목표가 아니다.
- **맥락**: PRD는 만료, 재시도, 제한, 파기의 구체 값을 ADR에서 정하게 했다. 세 에이전트의 제안(codex, agy, claude)을 종합했다.

| 이메일 묶음 / 디스코드 마감 임박 | 매일 08:00 / 09:00 (KST). 놓치면 당일 1회 만회 |
| 백업 | 매일 03:00, 보관 14일 |
