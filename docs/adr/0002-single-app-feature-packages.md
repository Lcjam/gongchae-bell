# ADR-0002 단일 앱, 기능별 패키지

- **상태**: 채택 (2026-11-08)
- **맥락**: 웹, 수집, 매칭, 발송이 모두 필요하다. 서버는 A1 한 대다.
- **선택지**: 단일 Spring Boot 앱 / 수집·발송 워커 분리 / 메시지 큐 도입
- **결정**: **단일 앱.** 패키지는 `catalog`, `ingestion`, `subscription`, `notification`, `ops`로 나눈다. 작업 조율은 PostgreSQL로 한다(ADR-0003, 0004). Redis, 큐, 별도 워커는 없다.
- **결과**: 배포 단위가 하나라 단순하다. 대신 수집 부하가 웹에 영향을 줄 수 있고, blue/green 중에는 두 앱이 같은 작업을 노리므로 DB 조율이 필수다. 이 영향은 성능 기준선으로 확인한다.
