# ADR-0008 토큰: 확인은 무작위, 관리·해지는 HMAC 파생

- **상태**: 채택 (2026-11-08)
- **맥락**: 로그인이 없어서 링크 토큰이 곧 권한이다. 매일 보내는 메일에 해지 링크를 넣어야 하는데, 해시만 저장하면 원문 토큰을 다시 만들 수 없다 (codex 지적).
- **선택지**: 원문 저장 / 해시만 저장하고 재발급 때 교체 / **서버 키로 파생**
- **결정**
  - **확인 토큰**: 32바이트 무작위 값. DB에는 SHA-256 해시, 만료 시각, 1회 사용 여부만 저장한다
  - **관리·해지 토큰**: `HMAC-SHA256(토큰 키, 목적 | 구독 ID | token_version)`. DB에는 `token_version`만 저장한다. 메일을 만들 때마다 같은 토큰을 다시 계산할 수 있다. 검증도 다시 계산해서 비교한다(상수 시간). `token_version`을 올리면 기존 링크가 모두 무효가 된다
  - 토큰 키는 환경변수로 둔다(DB, 백업과 분리)
- **결과**: 토큰 저장 테이블이 필요 없다. 토큰 키가 유출되면 모든 관리 링크를 위조할 수 있으므로, 키 교체 절차(버전 일괄 증가 + 새 키)를 runbook에 둔다.
