# ADR-0011 다중값 코드: 조인 테이블

- **상태**: 채택 (2026-11-08)
- **맥락**: API의 NCS, 지역, 고용형태, 학력은 쉼표로 이어진 여러 코드다(`ncsCdLst` 등). 목록 필터와 기관 NCS 분포에 원소 단위 질의가 필요하다.
- **선택지**: 쉼표 문자열(LIKE) / PostgreSQL 배열 + GIN / **조인 테이블**
- **결정**: `posting_code(sn, type, code)`, PK(`sn`, `type`, `code`), 인덱스(`type`, `code`, `sn`). 표시명은 응답의 `*NmLst`로 `code_name`을 채운다 (코드표 PDF는 파싱하지 않는다).
- **결과**: 표준 JPA와 SQL로 필터(`EXISTS`)와 집계(`GROUP BY`)를 할 수 있다. 행 수는 늘어나지만 3년치(약 3.5만 건 추정) 규모에서는 문제가 없다. 쉼표 문자열의 부분 일치 오류가 없다.
